# Writely — установка и обновления

[Скачать для Windows x64](https://github.com/dmmhm/writely-releases/releases/download/v0.2.4/Writely_0.2.4_windows-x64-setup.exe) · [Скачать для Mac Apple Silicon](https://github.com/dmmhm/writely-releases/releases/download/v0.2.4/Writely_0.2.4_macos-arm64.app.tar.gz) · [Выпуск 0.2.4](https://github.com/dmmhm/writely-releases/releases/tag/v0.2.4)

Скачивание и обновления доступны без входа в GitHub. Исходный код приложения в этом репозитории не публикуется.

## Обновление установленного приложения

Из 0.2.3 установите 0.2.4 через `/настройки` → «Обновления…».

Для перехода с 0.2.2 и более старых версий один раз установите актуальную версию вручную:

- Windows: закройте Writely и запустите новый установщик поверх прежней версии.
- Mac Apple Silicon: закройте Writely, распакуйте архив и замените Writely.app в папке приложений.

В дальнейшем Writely сама проверяет стабильные обновления при запуске, раз в четыре часа и после возвращения сети. Новая версия появляется кнопкой в приложении. Ручная проверка — `/настройки` → «Обновления…».

Нажмите «Скачать обновление», затем «Установить и перезапустить». Перед установкой приложение сохраняет документы. Во время записи, распознавания и облачной обработки завершите текущую операцию и повторите обновление. Документы, записи, настройки и отдельно скачанная GigaAM хранятся отдельно от файлов приложения.

Обновления пока скачиваются полным пакетом. Для них не нужны токен GitHub или ключ GigaChat.

## Локальное распознавание

В `/настройки` → Аудио можно выбрать Whisper или GigaAM v3 для русской речи. Whisper включён в установщик. Для GigaAM один раз нажмите «скачать модель» (~327 МБ), затем распознавание работает без интернета и выдаёт текст после остановки записи.

В `/аудио` → «проверка распознавания» → «проверить этот компьютер» есть отдельный замер скорости каждой модели. Тест использует встроенную синтетическую речь, не микрофон и не ваши документы. После замера проверьте 3–5 минут своей речи. При повторном распознавании аудио прежняя расшифровка заменяется; сохраните нужный текст перед сравнением.

В 0.2.4 добавлены нумерованные и маркированные списки с сохранением в Markdown, новое меню форматирования и действия GigaChat над выделенным текстом. Сохраняются переключение рабочих папок и локальное распознавание Whisper/GigaAM.

## Проверка пакетов

Пакеты подписаны ключом обновлений Writely; номер версии привязан к подписи. Контрольные суммы опубликованы в `SHA256SUMS`, подписи — в `.sig`. Подпись обновлений не заменяет сертификат издателя Windows: Authenticode пока отсутствует, Mac-сборка использует ad-hoc подпись.

Публичный выпуск содержит установщики, подписи, инструкции и `latest.json` для обновлятора. Черновики и предварительные выпуски не предлагаются обычным пользователям автоматически.
