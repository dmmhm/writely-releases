# Writely — установщики

Готовые установщики Writely и инструкции для проверки. Скачать опубликованные файлы можно без входа в GitHub.

## Windows 0.2.1

[Скачать установщик Windows x64](https://github.com/dmmhm/writely-releases/releases/download/v0.2.1/Writely_0.2.1_windows-x64-setup.exe) · [Страница тестового выпуска](https://github.com/dmmhm/writely-releases/releases/tag/v0.2.1)

Это тестовый выпуск с локальным распознаванием речи и проверкой скорости компьютера. Размер установщика — около 822 МБ; модель распознавания и Java включены. Для установки WebView2 может понадобиться интернет. Сертификата издателя Windows пока нет.

1. Установите приложение и выберите новую пустую рабочую папку для теста.
2. Введите `/аудио` на отдельной строке и нажмите Enter.
3. Откройте «проверка распознавания» → «проверить этот компьютер».
4. После проверки нажмите «копировать отчёт» и отправьте его в чат, где обсуждаете тестирование.
5. Запишите 3–5 минут речи и проверьте результат.

GigaChat и отдельная установка инструментов разработки для этого теста не нужны.

Контрольная сумма установщика опубликована в `SHA256SUMS`. Файл `.sig` содержит подпись системы обновлений; он не заменяет сертификат издателя Windows.

В этом репозитории размещаются только готовые выпуски и инструкции. Исходный код приложения здесь не публикуется.
