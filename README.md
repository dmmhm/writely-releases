# Writely — установщики

Готовые установщики Writely и инструкции для проверки. Скачать опубликованные файлы можно без входа в GitHub.

## Windows 0.2.2 · Whisper и GigaAM

[Скачать установщик Windows x64](https://github.com/dmmhm/writely-releases/releases/download/v0.2.2/Writely_0.2.2_windows-x64-setup.exe) · [Страница тестового выпуска](https://github.com/dmmhm/writely-releases/releases/tag/v0.2.2)

В настройках можно выбрать Whisper или GigaAM v3 для русской речи. GigaAM распознаёт локально после остановки записи; текст во время записи для него пока недоступен. Настройки Whisper сохраняются при переключении.

Размер установщика — около 835 МБ. Whisper и Java включены. Модель GigaAM скачивается отдельно один раз (~327 МБ), затем распознавание работает без интернета. Для установки WebView2 может понадобиться интернет. Сертификата издателя Windows пока нет.

1. Закройте Writely и запустите установщик новой версии.
2. Откройте `/настройки` → Аудио → выберите GigaAM → «скачать модель GigaAM».
3. Введите `/аудио` на отдельной строке, нажмите Enter и откройте «проверка распознавания» → «проверить этот компьютер».
4. После проверки нажмите «копировать отчёт» и отправьте его в чат, где обсуждаете тестирование.
5. Запишите 3–5 минут своей речи и оцените качество. Для сравнения вернитесь к Whisper в настройках.

Проверка скорости использует встроенную синтетическую речь. Микрофон, документы и облако для этого теста не используются. Скорость на вашем компьютере нужно измерить отдельно. При повторном распознавании аудио прежний текст заменяется; сохраните его перед сравнением.

Python и ключ GigaChat для локального распознавания не нужны. Облачная суммаризация — отдельная настройка, которую можно отключить.

Контрольная сумма установщика опубликована в `SHA256SUMS`. Файл `.sig` содержит подпись системы обновлений; он не заменяет сертификат издателя Windows.
