# slog

Настольный редактор для заметок, документов и записей разговоров. Пишите в Markdown, диктуйте текст, расшифровывайте аудио и экспортируйте документы в PDF. Редактор и распознавание речи работают локально.

**[Скачать последнюю стабильную версию](https://github.com/dmmhm/writely-releases/releases/latest)** · [Все выпуски](https://github.com/dmmhm/writely-releases/releases)

## Первая установка

В разделе **Assets** стабильного выпуска выберите полный пакет без `-update` в имени. Скачивание доступно без входа в GitHub.

| Платформа | Пакет | Установка |
| --- | --- | --- |
| Windows x64 | `slog_…_windows-x64-setup.exe` | Запустите установщик. |
| macOS 13.3 и новее, Apple Silicon | `slog_…_macos-arm64.app.tar.gz` | Распакуйте архив и перенесите `slog.app` в папку «Программы». |

Полные пакеты включают модели Whisper и компоненты для локальной проверки текста и экспорта PDF. Дополнительные сведения по установке есть в `INSTALLATION.txt` в каждом стабильном выпуске.

## Обновление

В версии 0.2.5 и новее откройте `//настройки` (в старом интерфейсе `/настройки`) → «Обновления…» → «Скачать обновление» → «Установить и перезапустить». Для более ранних версий скачайте полный установщик.

slog проверяет стабильные обновления при запуске, раз в четыре часа и при возвращении сети. При наличии проверенных моделей Whisper скачивается облегчённый пакет. Документы, записи и настройки хранятся отдельно от файлов приложения.

## Возможности

- Документы в обычных файлах Markdown и TXT. В Markdown доступны таблицы, списки задач и ссылки на файлы рабочей папки.
- Быстрая диктовка в документе и локальная расшифровка записей через Whisper. Для русской речи можно дополнительно скачать модель GigaAM.
- Проверка орфографии и грамматики на русском и английском, личный словарь и шаблоны.
- Экспорт PDF с предпросмотром A4. Облачные функции GigaChat можно включить отдельно.

## Проверка пакетов

В стабильном выпуске опубликованы `SHA256SUMS`, подписи `.sig` и ленты `latest.json` и `latest-lite.json`. Встроенный обновлятор проверяет подлинность пакета и его версию по подписи. Установщик Windows без Authenticode, приложение macOS с ad-hoc подписью.
